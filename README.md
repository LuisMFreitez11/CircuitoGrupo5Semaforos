# Semáforos Sincronizados con Arduino

Proyecto de la Electiva ELT-622 (Robótica) - IUJO - 6to Semestre.

Implementación de un cruce de semáforos sincronizados para dos calles,
con luces vehiculares y peatonales, controlado con una placa Arduino.

## Estructura del repositorio

- `Semaforos_Sincronizados/Semaforos_Sincronizados.ino` - Código fuente del Arduino
- `Entrega_Semaforo_*.md` - Documento de entrega de la práctica

## Uso

1. Abrir `Semaforos_Sincronizados/Semaforos_Sincronizados.ino` en el Arduino IDE.
2. Conectar la placa Arduino y cargar el programa.
3. El circuito debe conectarse según la asignación de pines descrita en el código.
